## Otrona

Developer for [SliTaz GNU/Linux](https://www.slitaz.org), and Korean input
on lightweight Linux distributions.

**In SliTaz** (official wok):
kime (Korean input method), rust for x86_64, meson15,
spice-vdagent / spice-protocol / xsel (clipboard sharing in QEMU),
and the x86_64 fix for get-LibreOffice.

**Projects:**
- [slitaz-kime](https://github.com/Otrona/slitaz-kime): kime, Korean fonts
  and live ISOs for SliTaz 5.1 (English / 한국어)
- [slitaz-qemu-clipboard](https://github.com/Otrona/slitaz-qemu-clipboard):
  SliTaz in QEMU with host clipboard
- [slitaz-rust-meson](https://github.com/Otrona/slitaz-rust-meson):
  Rust and meson for SliTaz 5.1
- [austrumi-ko](https://github.com/Otrona/austrumi-ko): AUSTRUMI with
  Korean input (fcitx5-hangul)

**Also:** [ristretto-scroll-mod](https://github.com/Otrona/ristretto-scroll-mod)
(Ristretto image viewer with 100% zoom and touchpad panning) and
[waterfox-slim-tabs](https://github.com/Otrona/waterfox-slim-tabs)
(an 18px tab bar for Waterfox and Firefox).
